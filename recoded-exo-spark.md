<h1>How to Get Exo Spark in Kingdom Hearts Re:coded</h1>
<p><strong>Exo Spark</strong> is a magic command with a memory cost of 20%. The in-game description reads: "Discharge a torrent of electricity that deals continual damage to surrounding foes." It has a single recipe, <strong>Triple Blizzaga + Thundaga</strong>, and it is not an ingredient in any other recipe, so nothing else needs to be saved for it.</p>

<h2>What to Keep Back</h2>
<p>Exo Spark is a dead end, but the commands that lead to it are not. <strong>Thundara</strong> and <strong>Thundaga</strong> are both needed again for Pulse Tracer (<strong>Thundara + Thundaga</strong>), which goes on to make Cyclone. Make a spare of each before you commit. Chain Rave is also an ingredient in <a href="/recoded-triple-pursuit">Triple Pursuit</a> and <a href="/recoded-triple-burst">Triple Burst</a>.</p>
