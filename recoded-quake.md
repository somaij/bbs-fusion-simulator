<h1>How to Get Quake in Kingdom Hearts Re:coded</h1>
<p><strong>Quake</strong> is a magic command with a memory cost of 15%. The in-game description reads: "Generate an earthquake that stuns and deals major damage to foes near the ground." It has a single recipe, <strong>Zantetsuken + Cyclone</strong>, and both of those are late-chain commands, so this is a long build.</p>
<p><em>Looking for the Birth by Sleep version?</em> That is a different command with different recipes. See <a href="/quake">How to Get Quake in KH BBS</a>.</p>

<h2>The Chain at a Glance</h2>
<p>Quake splits into two halves, each of which needs a lot of work:</p>
<ul>
    <li><strong>Zantetsuken</strong> is <a href="/recoded-judgment-triad">Judgment Triad</a> + <strong>Gravity Drop</strong>. Gravity Drop is <a href="/recoded-wind-tracer">Wind Tracer</a> + <strong>Chain Rave</strong>.</li>
    <li><strong>Cyclone</strong> is Wind Tracer + <strong>Pulse Tracer</strong>. Pulse Tracer is <strong>Thundara + Thundaga</strong>.</li>
</ul>
<p>Zantetsuken, Gravity Drop and Cyclone each have exactly one recipe, so there are no alternatives at those steps. The flexibility is underneath: Wind Tracer, Muscle Strike, Chain Rave and Pulse Tracer all have four recipes each.</p>

<h2>Shopping List</h2>
<p>Before you start, plan for all of the following:</p>
<ul>
    <li><strong>Three Wind Tracers.</strong> One each for Judgment Triad, Gravity Drop and Cyclone. This is the biggest cost. The <a href="/recoded-wind-tracer">Wind Tracer page</a> has a three-step route if you have Esuna.</li>
    <li><strong>One Muscle Strike.</strong> Rising Strike + Land Crash, as shown on the <a href="/recoded-judgment-triad">Judgment Triad page</a>.</li>
    <li><strong>One Chain Rave.</strong> Fire Raid + Spark Dive, or Aeroga + Curaga. See <a href="/recoded-best-commands">Best Commands</a>.</li>
    <li><strong>Two Thundara and one Spark Storm</strong>, to make Thundaga and then Pulse Tracer. The Thundaga route is on the <a href="/recoded-exo-spark">Exo Spark page</a>.</li>
</ul>
<p>Quake is not an ingredient in any other recipe in the calculator, so it is the end of the line.</p>
