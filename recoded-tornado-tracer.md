<h1>How to Get Tornado Tracer in Kingdom Hearts Re:coded</h1>
<p><strong>Tornado Tracer</strong> is a magic command with a memory cost of 18%. The in-game description reads: "Shoot a gust of wind that homes in on enemies and keeps them airborne." It has 5 recipes, and one of them, <strong>Firaga + Curaga</strong>, uses two commands the <a href="/recoded-best-commands">Best Commands guide</a> already has you build.</p>
