<h1>How to Get Triple Pursuit in Kingdom Hearts Re:coded</h1>

<p>It sits in a pair with <strong>Blizzaga Pursuit</strong>: Triple Pursuit + Blizzaga makes Blizzaga Pursuit, and Blizzaga Pursuit + Triple Blizzaga makes Triple Pursuit. Blizzaga Pursuit also has a recipe that does not need Triple Pursuit at all, <strong>Muscle Strike + Stun Impact</strong>, so there is no reason to cycle between them.</p>
<p>The Triple Firaga recipe here uses a finished Triple Pursuit. Triple Firaga has other recipes, such as <strong>Heat Dive + Firaga</strong>, so only use this one if you have a spare Triple Pursuit.</p>
